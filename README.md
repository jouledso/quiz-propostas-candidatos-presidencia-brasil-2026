# Quiz às cegas — Propostas para a Presidência do Brasil 2026

## Sobre o projeto

O **Quiz às cegas** foi criado para permitir que o usuário compare propostas dos candidatos à Presidência da República sem saber, no momento da avaliação, qual candidato apresentou cada proposta.

> **Primeiro avalie a proposta. Depois descubra quem a propôs.**

O objetivo é reduzir a influência de identificação partidária, nome, número ou preferência prévia durante a comparação das propostas.

## Como funciona

- As propostas são apresentadas **sem identificação do candidato**.
- A ordem das propostas é **randomizada** para reduzir padrões que possam revelar a autoria.
- O usuário responde se **concorda**, **é neutro/considera que depende** ou **discorda**.
- As propostas são organizadas por temas.
- Ao final de cada tema, a autoria é revelada e o quiz apresenta com qual candidato houve maior concordância.
- O resultado geral reúne os diferentes temas para mostrar o padrão de concordância.
- As referências indicam onde as informações utilizadas podem ser verificadas nos documentos oficiais.

## Objetivo e neutralidade

O quiz não tem como objetivo recomendar um candidato ou indicar em quem o usuário deve votar.

Seu objetivo é facilitar uma comparação baseada nas propostas apresentadas nos documentos oficiais, tentando minimizar vieses de identificação durante a avaliação.

A ordem das propostas é randomizada e os nomes dos candidatos são ocultados até o momento dos resultados.

## Fontes

As propostas utilizadas no quiz são baseadas nos documentos de propostas de governo registrados pelas candidaturas junto ao **Tribunal Superior Eleitoral (TSE)**.

As referências apresentadas nos resultados permitem consultar a página e o trecho correspondente do documento utilizado como fonte.

## Importante

O resultado representa apenas a **concordância do usuário com as propostas apresentadas no questionário**.

Ele não constitui uma avaliação completa dos candidatos e não considera, entre outros fatores:

- histórico político;
- histórico de gestão;
- capacidade de execução;
- viabilidade econômica ou jurídica;
- alianças políticas;
- posicionamentos fora dos documentos analisados;
- outros fatores relevantes para uma decisão de voto.

## Tecnologia

O projeto foi desenvolvido como uma aplicação web estática utilizando:

- HTML
- CSS
- JavaScript

Não é necessário banco de dados ou servidor para executar o quiz.

## Publicação

O projeto pode ser publicado gratuitamente utilizando **GitHub Pages**.

1. Coloque o arquivo `index.html` na raiz do repositório.
2. Acesse **Settings → Pages**.
3. Em **Source**, selecione **Deploy from a branch**.
4. Escolha a branch `main`.
5. Escolha `/ (root)`.
6. Clique em **Save**.

O GitHub Pages disponibilizará uma URL pública para o quiz.
